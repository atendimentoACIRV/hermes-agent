## 3\. Como a matriz classifica a adoção

O inventário não significa que todos esses projetos já estejam integrados ao Hermes. O Source Matrix distingue\:

| Classificação | Significado |
|--------|--------|
| KEEP + MODIFY MINIMALLY | Manter o componente e modificar pouco |
| ADAPT CODE/PATTERNS | Aproveitar código ou padrões específicos |
| ADAPT IDEA/CONTRACT | Aproveitar a ideia ou contrato, sem incorporar a implementação |
| KEEP EXTERNAL | Integrar externamente, sem internalizar o motor |
| REFERENCE | Estudar como referência |
| REFERENCE/EVAL | Usar como comparação ou avaliação |
| BENCHMARK CANDIDATE | Comparar implementações antes de decidir |
| DO NOT INTEGRATE | Não integrar à arquitetura |

Além disso, o documento diferencia `FACT` \(verificado), `PARTIAL` \(verificação parcial) e `NV` \(não verificado).
